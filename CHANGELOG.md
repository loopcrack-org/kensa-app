# Changelog

All notable end-user changes to Kensa are documented here.

## Unreleased — v0.1.14

- First signed & notarized macOS build (Developer ID + Apple notarization);
  no more `xattr` workaround on install.
- GitHub → Kensa Companion launch channels qualified on Windows: browser
  extension ("Open in Kensa") and organization Check → deep link.
- Multi-provider support: GitHub, GitLab and Bitbucket Cloud via direct API
  integration (no `gh` CLI dependency).
- Releases now published from this public repository; the in-app updater
  follows it automatically.

## v0.1.13 and earlier

Internal development builds, published from the private repository.
